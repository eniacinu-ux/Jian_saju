[일진달력 날짜 상세 기능 추가]

1. 달력의 날짜 숫자를 클릭하면 해당 날짜의 전체 행사 일진 상세창 표시
2. 행사 필터 선택 여부와 무관하게 원본 날짜 데이터 전체를 표시
3. 상세창 상단에 날짜 + 일진(간지) 표시
4. 길한 행사: 주황/적색 계열 칩으로 전체 표시
5. 흉한 행사: 청색 계열 칩으로 전체 표시
6. 길/흉 행사 개수 표시
7. 諸事不宜 날짜는 '모든 일을 삼가는 날'로 별도 강조
8. 데이터 범위 밖 날짜는 행사 길흉 데이터 없음 안내
9. 상세창 바깥 클릭 또는 X 버튼으로 닫기
10. 일진달력 자체를 닫을 때 날짜 상세 선택 상태도 초기화
